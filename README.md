# Cinevault -Movie & TV Discovery App

## Project Overview
CineVault is a modern movie and television discovery web application designed to help users explore trending and popular movies and TV shows in one place. The project focuses on building a visually appealing, responsive, and user-friendly interface while demonstrating practical frontend development skills through API integration, component-based architecture, routing, search functionality, and state management.

The application will integrate with The Movie Database (TMDB) API to retrieve movie and television data, including titles, posters, ratings, release dates, and descriptions. Users will be able to discover entertainment content, search for specific titles, and navigate through an organized collection of movies and TV shows.
